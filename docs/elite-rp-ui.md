# Elite RP Launcher UI direction

- Brand: Elite RP
- Language: Armenian UI
- Style: premium dark glass / minimal gaming launcher
- Window: compact desktop app, rounded/beveled frame, no page scrollbar
- Main: large background scene, Elite RP logo, nickname field, large Play button
- Right panel: server online status, players, ping, server selector
- News: compact cards
- Footer: social links, version, update progress
- UX: no visible PowerShell/console window when launched
- Windows: native-feeling window controls and icon
